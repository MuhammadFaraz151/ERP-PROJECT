ERP Billing System

A comprehensive billing and inventory management system built with React, Node.js, and MongoDB.

Features

Dashboard: Real-time sales, profit, revenue, and invoice statistics.

Inventory Management: Product catalog, stock tracking, and expiry monitoring.

Invoice Generation: Professional invoices with GST calculations.

Sales & Reports: Track payments, balances, and generate reports.

Customer Management: Manage customer profiles and transaction history.

Supplier Management: Track purchases and supplier payments.

Refund System: Process and track invoice refunds.

Dark/Light Mode: Switch between themes.

Tech Stack

React

Node.js

Express.js

MongoDB

Redux Toolkit

Tailwind CSS
